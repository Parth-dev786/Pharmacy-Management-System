
# Pharmacy Management System

### Group 5 | Java Swing Desktop Application

A Java-based Pharmacy Management System designed to manage medicine inventory, expiry tracking, sales billing, supplier records and stock reports.

## Features

- Medicine Management (Add, Update, Delete, Search)
- Medicine Expiry Tracking
- Sales Billing and Stock Updates
- Supplier Management
- Stock Reports and CSV Export
- Local Data Persistence

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming
- Java Serialization
- CSV File Handling

## How to Run

1. Install the required JDK (JDK 24 as specified for this project).
2. Extract or clone this repository.
3. Open the project in IntelliJ IDEA.
4. Open `src/com/college/pharmacy/PharmacyApp.java`.
5. Run the `main()` method.

Alternatively, on Windows, execute `RUN.bat`.
